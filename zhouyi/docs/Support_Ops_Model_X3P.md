Notice: The QDQ(float) structure is

    uint8/int8 type tensor  -> DequantizeLinear -> float tenosr  ->  OP (float)  -> QuantizeLinear -> uint8/int8 type tensor

Unless otherwise specified, OPs that support float also support QDQ(float).

# Supported Models

The following models from the ONNX model zoo are supported using the Zhouyi Execution Provider:
mnist-12-int8
resnet50-v1-12-int8
resnet50-v1-12-qdq
mobilenetv2-12-int8
mobilenetv2-12-qdq
inception-v1-12-int8
inception-v1-12-qdq
vgg16-12-int8
vgg16-12-qdq
Model from:
https://github.com/onnx/models/tree/main/validated

Notice:Zhouyi does not support dynamic shapes.
